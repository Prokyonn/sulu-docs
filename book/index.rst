The Book
========

When you work through the book, you'll build a website based on Sulu from scratch. First, we will explain some of our
very basic design decisions. Based on that, we'll get your project started.

Be sure to know a thing or two about `Symfony`_. Sulu is based on Symfony and is structured according to the Symfony
standards. If you don't know how to work within the Symfony framework, you might encounter some problems when using
Sulu.
