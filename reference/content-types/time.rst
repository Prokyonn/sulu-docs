Time
====

Description
-----------

Displays a text line where the inserted content is validated against a
time string and saved as a simple string.

Parameters
----------

No parameters available.

Example
-------

.. code-block:: xml

    <property name="time" type="time">
        <meta>
            <title lang="en">Time</title>
        </meta>
    </property>

Twig
----

.. code-block:: twig

    {{ content.time }}
